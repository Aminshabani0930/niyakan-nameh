# نیاکان نامه (Next.js + Postgres + NextAuth)

```bash
npm install
cp .env.example .env     # مقادیر را پر کنید
npx prisma migrate deploy
npm run dev
```

## متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | آدرس اتصال pooled برنامه به Postgres |
| `DIRECT_URL` | آدرس مستقیم همان دیتابیس برای migrationهای Prisma (در Neon از Direct connection استفاده کنید) |
| `NEXTAUTH_URL` | آدرس کامل برنامه (روی Render با https) |
| `NEXTAUTH_SECRET` | `openssl rand -base64 32` |
| `APP_PASSWORD` | رمز ورود به برنامه |
| `CRON_SECRET` | کلید محافظت از مسیرهای کران |
| `AI_API_KEY` | کلید GapGPT |
| `AI_BASE_URL` | endpoint سازگار با OpenAI |
| `AI_TEXT_MODEL` | نام مدل متن |
| `AI_FAST_MODEL` | مدل سبک دسته‌بندی و خلاصه؛ پیش‌فرض `gpt-5.6-luna` |
| `AI_REVIEW_MODEL` | مدل بازبینی ارجاع؛ پیش‌فرض `gpt-5.6-sol` |
| `AI_FALLBACK_MODEL` | جایگزین خطا؛ پیش‌فرض `gapgpt-qwen-3.5` |
| `AI_IMAGE_MODEL` | نام مدل تصویر؛ تمام تصویرهای تولیدی در Cloudinary ذخیره می‌شوند |
| `AI_IMAGE_SIZE` | `1024x1536` |
| `AI_IMAGE_STYLE` | سبک تصویر؛ پیش‌فرض نگارگری ایرانی |
| `AI_CAROUSEL_SLIDES` | تعداد اسلاید پیشنهادی کاروسل |
| `AGENT_MAX_IMAGES_PER_RUN` | سقف تصویر در هر اجرای ایجنت |
| `CLOUDINARY_*` | آپلود رسانه و ذخیره‌ی همه‌ی تصویرهای تولیدی |
| `IG_USER_ID` / `IG_ACCESS_TOKEN` | انتشار و آمار اینستاگرام (Business/Creator) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | خلاصه‌ی روزانه |

> اگر endpoint تصویر خطا دهد، پیش‌نویس متنی حفظ می‌شود و خطای تصویر جداگانه ثبت می‌شود.

## ایجنت برنامه‌محور

- صفحه‌ی `/plan`: مدیریت PlanItemها، ویرایش، حذف، ورود چندتایی از متن/CSV و تقویم محتوا.
- صفحه‌ی `/agent`: تولید پیش‌نویس برای یک آیتم یا آیتم‌های هفته‌ی آینده.
- صفحه‌ی `/settings`: وضعیت متغیرهای محیطی و نام مدل‌های تنظیم‌شده.
- صفحه‌ی `/library`: ثبت منبع، ورود متن، جست‌وجو، reader آفلاین و مدیریت کتابخانه.
- صفحه‌ی `/cyrus`: مدخل‌های کوروش؛ فقط موارد تأییدشده نمایش داده می‌شوند.
- صفحه‌ی `/calendar`: تقویم پیشنهادی هفت‌روزه؛ هیچ انتشار خودکاری انجام نمی‌شود.
- ایجنت فقط روزهای خالی را پر می‌کند و روزهای دارای محتوا را دست نمی‌زند.
- انتشار خودکار وجود ندارد؛ محتوا فقط پس از تأیید دستی قابل انتشار است.

## کتابخانه، پژوهش و تقویم

- ابتدا migration جدید را طبق ترتیب فایل‌های `prisma/migrations/` بررسی و روی دیتابیس اجرا کنید؛ migration در زمان توسعه به‌صورت خودکار اجرا نمی‌شود.
- از `/library` نام منبع و مجوز را وارد کنید. آپلود مرورگر حداکثر ۵MB است؛ فایل‌های بزرگ‌تر را طبق [data/README.md](data/README.md) با `npm run import:source` از `data/` وارد کنید.
- PDF اسکن‌شده متن ندارد و به OCR بیرونی نیاز دارد. اپ هیچ OCR یا متن شاهنامه‌ای تولید نمی‌کند.
- `data/topics.json` و `data/occasions.json` عمداً خالی‌اند؛ موضوع‌ها و مناسبت‌ها فقط با داده‌ی خودتان پیشنهاد می‌شوند.
- متن پژوهش AI باید به source chunkهای بازیابی‌شده ارجاع دهد؛ همه‌ی خروجی‌ها ابتدا در وضعیت بازبینی می‌مانند.
- خانواده‌های متنی مجاز GapGPT: `gpt-5.6-terra`، `gpt-5.6-luna`، `gpt-5.6-sol`، `gapgpt-qwen-3.5` و مدل‌های Gemini فقط از endpoint سازگار GapGPT. درخواست‌ها از `src/lib/ai.ts`، با timeout هشت‌ثانیه‌ای و fallback محدود عبور می‌کنند.
- پژوهشگر و تحلیل شکاف: `/research`. تأیید خودکار جای تأیید انسانی را نمی‌گیرد و ویرایش متن، بازبینی خودکار را باطل می‌کند.
- الگوی تقویم پیش‌فرض: ۳ ریلز و ۳ کاروسل در هفته، ۴ استوری روزانه در صبح/ظهر/عصر/شب. ساعت‌ها در `/settings` قابل تغییرند.
- Render Cron باید با `digestTime` تهران هماهنگ باشد؛ زمان schedule در Render بر اساس UTC است. خلاصه‌ی تلگرام فقط در همان زمان و در صورت تنظیم Telegram فرستاده می‌شود.
- ذخیره‌ی آفلاین منبع روی IndexedDB همان مرورگر است و به فضای آزاد دستگاه وابسته است. سرویس Render رایگان و دیتابیس Neon محدودیت مصرف/خواب دارند؛ مصرف واقعی دیتابیس در `/settings` نمایش داده می‌شود.

## کران

- `GET /api/cron/daily` — تولید پیش‌نویس PlanItemهای برنامه‌ریزی‌شده تا سه روز آینده و اطلاع‌رسانی تلگرام.
- مسیر کران با هدر `Authorization: Bearer $CRON_SECRET` محافظت می‌شود.

روی Render یک Cron Job بسازید که روزانه این آدرس را صدا بزند. جزئیات در `RENDER-SETUP.md`.

## نصب روی اندروید

این برنامه به‌صورت PWA قابل نصب است و APK مستقل نیست. ابتدا برنامه را روی یک دامنه‌ی عمومی با HTTPS میزبانی کنید و متغیرهای محیطی و دیتابیس را در همان محیط تنظیم کنید. سپس در Chrome اندروید نشانی سایت را باز کنید و از منوی مرورگر «نصب برنامه» یا «افزودن به صفحه اصلی» را بزنید.

- دیتابیس: یک Postgres (مثلاً رایگان در Neon یا Supabase) بسازید و آدرس را در `DATABASE_URL` بگذارید.
- لاگین: `NEXTAUTH_SECRET` را با `openssl rand -base64 32` بسازید. رمز ورود همان `APP_PASSWORD` است.
- روی Render: همه‌ی متغیرهای `.env` را در Environment Variables بگذارید، `NEXTAUTH_URL` را به آدرس سایت تغییر دهید، و یک‌بار `npx prisma migrate deploy` را روی دیتابیس اجرا کنید.

- یادآوری ضبط بر اساس `recordDate` انجام می‌شود؛ تاریخ پیش‌فرض ضبط دو روز پیش از انتشار است.
- تست تلگرام در PowerShell: `Invoke-WebRequest -Headers @{ Authorization = "Bearer $env:CRON_SECRET" } http://localhost:3000/api/cron/daily`
